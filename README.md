## <a name="-about"></a>◆ ABOUT ME

<table width="100%">
<tr>
<td width="60%" valign="top">
<div>

I'm a **Computer Science Engineering graduate** working at the intersection of **applied AI** and **full-stack software engineering**. I don't treat AI as a buzzword bolted onto a project — I design systems where an LLM's reasoning is a real architectural component, wired into APIs, databases, and interfaces that behave predictably under real usage.

My engineering philosophy is simple: **clarity beats cleverness**. Clean data models, typed APIs, and interfaces that don't get in the user's way. I build with `FastAPI`, `React`, and `PostgreSQL` as a default stack, and I reach for `Google Gemini` and `IBM Watsonx` when a problem genuinely needs language understanding rather than more `if` statements.

Right now, I'm focused on **retrieval-augmented generation**, **natural-language-to-SQL systems**, and shipping **production-grade ML** — not notebooks that never leave a laptop.
